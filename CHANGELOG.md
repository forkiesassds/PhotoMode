## Additions
- Added support for Minecraft 26.2
- Added an option to preserve the Picture Mode state when exiting the GUI

## Changes
- Increased frame delay when taking screenshots
  - This shouldn't be noticeable, but should also help resolve issues with chunk culling when taking a screenshot.

## Removals
- Removed support for VulkanMod
  - It was experimental, and had plenty of issues. Consider updating to 26.2 if you want to use Vulkan.
